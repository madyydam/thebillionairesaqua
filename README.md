## 💎 Overview

**The Billionaires Aqua** represents the pinnacle of artisanal bottling and geological filtration. Bottled at source beneath pristine alpine glaciers, each bottle encapsulates untouched mineral purity, crafted for private collections, high-end hospitality, and bespoke events.

- **Source Elevation:** 3,450m Alpine Stratum
- **Filtration Cycle:** 400-Year Volcanic Basalt Micro-Purification
- **Natural Alkalinity:** pH 8.4 Balanced
- **Packaging:** Hand-Blown Double-Wall Fluted Borosilicate Crystal with 24K Gold Detailing

## ⚡ Quick Start

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm / yarn / pnpm / bun

### Installation

```bash
# Clone the repository
git clone https://github.com/madyydam/thebillionairesaqua.git

# Navigate into project directory
cd thebillionairesaqua

# Install dependencies
npm install

# Start development server
npm run dev
```
